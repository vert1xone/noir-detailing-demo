# NOIR DETAILING

Учебный проект сайта для вымышленной студии детейлинга. Одностраничный сайт оформлен в сдержанном премиальном стиле и представляет услуги, подход к работе и демонстрационный образ бренда.

**Демо:** [https://vert1xone.github.io/noir-detailing-demo/](https://vert1xone.github.io/noir-detailing-demo/)

## Технологии

- HTML
- CSS
- JavaScript

Разметка, стили и скрипты находятся в `index.html`. Для запуска не нужны сборка и установка зависимостей. Шрифты и фотографии загружаются из внешних источников, поэтому для их отображения требуется интернет-соединение.

## Основные функции

- Адаптивная вёрстка для разных размеров экрана.
- Навигация по разделам сайта и мобильное меню.
- Презентация услуг, принципов работы, галереи и демонстрационных цен.
- Интерактивный FAQ.
- Анимация появления блоков при прокрутке с учётом настройки уменьшения движения.
- Демонстрационная форма заявки с проверкой заполнения. Данные не отправляются и не сохраняются.

## Локальный запуск

1. Скачайте или клонируйте проект.
2. Откройте `index.html` в браузере.

При желании сайт можно запустить через локальный HTTP-сервер из корня проекта:

```bash
python -m http.server 8000
```

Затем откройте [http://localhost:8000](http://localhost:8000).

## Примечание

NOIR DETAILING — учебный проект для вымышленной компании. Изображения в галерее используются как иллюстрации и не являются портфолио выполненных работ; цены приведены для демонстрации макета. Форма заявки демонстрационная: введённые данные никуда не передаются.
